# AP-27 Critical product review and operational handoff

The final review checked actual source, configuration/authority boundaries, release archive, real
controller, Admin and all 36 scenarios. It found an overlapping-function ownership gap in beta 1:
functions sharing one physical output could declare inconsistent limits. Beta 2 rejects this in
whole-configuration validation and again at the executor boundary, including raw unvalidated callers.
Rules/conditions/limits must be combined into one function per output, even for disabled aliases.
Atomic controller rejection, essential-alias and raw manual-boundary regressions were added. The
public beta 1 notes immediately documented the issue; its released bytes/tag were not replaced.

Beta 2 currently passes 52 unit/contract and 61 official package tests, type checking and lint.
