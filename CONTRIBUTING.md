# Contributing

Use Node.js 22.19+ or 24, run `npm ci`, `npm run build`, `npm test` and `npm run test:integration`.
Submit small changes with reproducible, synthetic examples. Do not attach household
configuration, device identifiers, credentials or raw controller logs to issues.
Integrations must use the versioned capability contract and a selected state allowlist.
Document backend versions and distinguish emulator results from physical tests.
