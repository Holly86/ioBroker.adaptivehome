Deutsch · English

Von vorhandenen Geräten zur gemeinsamen Regel

Herstelleradapter verbinden deine Geräte mit ioBroker. Adaptive Home verknüpft deren Fähigkeiten und ergänzt Regeln. Geräteanmeldung und Zugangsdaten bleiben beim Herstelleradapter. Ein zweites Herstellerkonto ist nicht nötig.

  1. Im Admin-Reiter Adaptive Home → Geführte Einrichtung die gewünschte Instanz wählen. Räume oder Anlagen benennen und die Zeitzone festlegen.
  2. Installierte Adapter laden, konkrete Instanz auswählen und deren Geräte suchen. Es werden vorhandene Objektbeschreibungen gelesen; kein Aktor wird getestet und kein Dienst gestartet. „Aktiviert“ bedeutet nicht „frische Gerätewerte“.
  3. Gerät auswählen, eigenen Namen vergeben und zunächst Nur Daten lesen wählen. Für ein steuerbares Gerät sind passende Schreib-/Rückmeldepunkte und die ausdrücklich geprüfte alleinige Zuständigkeit nötig. Bereits eingerichtete Geräte unter Geräte & Bereiche bearbeiten.
  4. Für eine Alltagsfunktion Bereich, Vorlage, passenden Ausgang und Sensoren auswählen. Licht nutzt Bewegung und Lux, Klima eine echte Messtemperatur, Luft einen Luftqualitätssensor. Zeitpläne gelten in der gewählten Zeitzone. Nachläufe werden in Minuten eingegeben.
  5. Deaktivierte Funktion zum Entwurf hinzufügen bereitet die Regel vor. Neue Funktionen bleiben deaktiviert und erhalten keine Lernfreigabe. Unter Funktionen Details, Grenzen und Handvorrang prüfen.
  6. Optional eine vorhandene SQL-Instanz zur Protokollierung eigener Adaptive-Home-Daten wählen. Beobachtungen und Ereignisse sind getrennt wählbar. Keine Historienfreigabe fremder Datenpunkte; kein InfluxDB-Export.
  7. Entwurf prüfen validiert, Änderungen aktivieren speichert den gesamten Entwurf. Bereits aktive Funktionen können danach mit geänderten Einstellungen arbeiten. Neue vorbereitete Funktionen bleiben aus. Neu laden verwirft ungespeicherte Änderungen.

Erweitert arbeiten

Die detaillierten Formulare bleiben erhalten. Unter Import & Kanäle → Erweiterte Konfiguration (JSON) ist der vollständige Entwurf bearbeitbar. JSON zuerst prüfen und als Entwurf übernehmen; erst danach aktivieren. Fehler behalten den gültigen Entwurf und den eingegebenen Text. Zwischenzeitliche Formularänderungen werden nicht durch veraltetes JSON überschrieben. Die Schaltfläche „JSON durch aktuellen Formularentwurf ersetzen“ verwirft den Editorinhalt zugunsten der aktuellen Formulare.

Technische JSON-Zeiten sind überwiegend Millisekunden: 1200000 entspricht 20 Minuten. Wochenzeiten sind HH:MM in der gewählten Zeitzone. Gerätekennungen, Räume und gegebenenfalls Empfänger im Editor sind private Installationsdaten. Zugangsschlüssel gehören in geschützte Einstellungen.

Was eine Vorbereitung noch nicht belegt

Ein entdecktes Gerät und ein gültiger Entwurf sind keine Hardwareabnahme. Fehlende Daten bleiben unbekannt. Der Lernmodus Beobachten stoppt klassische Regeln nicht. Ein reiner Lesepilot hat keine aktiven Steuerfunktionen, Szenen oder externen Bedienfreigaben. Vor Aktorübergabe müssen Rückmeldung, Handbedienung, Ablauf und Rückweg geprüft sein. Ein normaler Heizsollwert ist kein autonom befristetes Heizprofil. Essenzieller Dauerbetrieb benötigt eine ausdrückliche Mindestfunktion und Schutzregeln in den erweiterten Formularen.

Die ausführliche Anleitung ist im Paket als docs/setup.de.md enthalten und online verfügbar. Diese Hilfeseite funktioniert ohne Internetverbindung.

Connect existing devices with shared rules

Manufacturer adapters provide device communication and authentication. Adaptive Home connects their capabilities and adds rules. No second manufacturer account is created.

  1. Open Adaptive Home → Guided setup in Admin. Choose the instance, name rooms or installations and select the schedule time zone.
  2. Load installed adapters, select the concrete instance and find its devices. Discovery reads existing object descriptions, without testing actuators or starting services. An enabled adapter is not evidence of fresh measurements.
  3. Select a device and give it a readable name. Start with Read data only. Preparing control requires suitable writes/feedback and explicitly reviewed sole ownership. Edit existing mappings in Devices & areas.
  4. Select the everyday function template, area, output and inputs. Motion lighting needs motion and illuminance; climate needs measured temperature; air needs an air-quality measurement. Holds use minutes and schedules use the selected time zone.
  5. Add the function to the draft. New functions remain disabled, use classic rules and have no learning permission. Review limits and manual priority under Functions.
  6. Optionally select an existing SQL adapter for Adaptive Home observations and generated events. This does not enable history on foreign states; InfluxDB export is not supported here.
  7. Validate draft checks; Activate changes saves the entire draft. Existing enabled functions may then operate under changed settings. New prepared functions remain disabled. Reload discards unsaved edits.

Advanced configuration

Detailed forms remain available. Under Import & channels → Advanced configuration (JSON), edit the complete draft, validate and transfer it to the forms, then explicitly activate. Invalid JSON preserves the valid draft and edited text. Stale JSON cannot replace a form draft that changed meanwhile. Replacing JSON with the current form draft discards the editor contents.

Technical JSON durations mostly use milliseconds: 1200000 is 20 minutes. Weekly times use HH:MM in the chosen time zone. Editor copies containing device IDs, areas or recipients are private installation data. Keep secrets in protected settings.

Preparation is not physical acceptance

Discovery and validation do not prove real hardware behavior. Missing measurements remain unknown. Learning mode Observe does not stop classic rules. A strict read-only pilot has no enabled control functions, scenes or external control grants. Handoff needs verified feedback, manual control, expiry and rollback. An ordinary setpoint is not an autonomously expiring heating profile. Essential continuous equipment needs explicit minimum service and protection in advanced forms.
