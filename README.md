# ioBroker.adaptivehome

Adaptive Home is under active implementation. The initial scaffold is not a usable automation release.

A configurable ioBroker adapter for rooms and user-named installations, capability-based integrations,
classical rules and optional local learning. Device backends, notifications and language models are optional.

Development: Node.js 22.19+ or 24; `npm ci`, `npm run build`, `npm run test:package`.
The authoritative implementation and verification state is in
[the work package manifest](docs/implementation/work-packages.json).
